# Activación del perfil y del juego

Los archivos ya están preparados para la dirección final https://rubeninfantes.github.io/rubeninfantes/.

1. En Settings → General del repositorio, cambia su nombre de `Ruben-Infantes` a `rubeninfantes`. Debe coincidir con tu usuario para mostrar README.md en tu perfil. Mantén el repositorio público.
2. En Settings → Pages, en Build and deployment elige **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/ (root)**. Pulsa **Save**.
4. Espera a que GitHub indique que la página está publicada. Abre la dirección del juego.

Tu perfil es https://github.com/rubeninfantes.

Si decides mantener el nombre Ruben-Infantes, la dirección de Pages será https://rubeninfantes.github.io/Ruben-Infantes/ y tendrás que sustituir los dos enlaces del README. En ese caso el README solo decorará el repositorio, no el perfil.

## Ejecutar localmente

Descarga el repositorio y abre index.html en un navegador. No necesita instalación ni servidor. El récord depende del almacenamiento local del navegador; si está bloqueado, se conserva solo durante la sesión.

## Archivos

- index.html: estructura del juego.
- style.css: diseño adaptable.
- game.js: lógica, controles y almacenamiento del récord.
- banner.svg: portada enlazada desde el README.

Las fuentes de Google Fonts son opcionales: sin conexión se utilizan fuentes del sistema. El juego no necesita servicios externos ni envía la puntuación a ningún servidor.
