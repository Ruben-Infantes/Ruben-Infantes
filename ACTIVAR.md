# Activación del juego

Tu usuario y tu repositorio ya se llaman `Ruben-Infantes`; no necesitas renombrarlos.

1. Abre https://github.com/Ruben-Infantes/Ruben-Infantes/settings/pages.
2. En Build and deployment elige **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**, y pulsa **Save**.
4. Cuando GitHub confirme la publicación, abre https://ruben-infantes.github.io/Ruben-Infantes/.

Tu perfil: https://github.com/Ruben-Infantes.

## Ejecutar localmente

Descarga el repositorio y abre index.html en un navegador. No necesita instalación ni servidor. El récord depende del almacenamiento local del navegador; si está bloqueado, se conserva solo durante la sesión.

## Archivos

- index.html: estructura del juego.
- style.css: diseño adaptable.
- game.js: lógica, controles y almacenamiento del récord.
- banner.svg: portada enlazada desde el README.

Las fuentes de Google Fonts son opcionales: sin conexión se utilizan fuentes del sistema. El juego no necesita servicios externos ni envía la puntuación a ningún servidor.
